# Project Overview

**Syntera ERP** — sistem ERP untuk bisnis IT infrastructure & project services (Network, CCTV, Fiber Optic, Data Center, dll). Cakupan modul: Quotation (penawaran bertingkat Tab→Group→Item), Sales Order, Purchasing (Purchase Request→Purchase Order), Inventory (stock in/out, delivery order), Finance (Invoice, AR/AP, Cash In/Out), Project Management, dan Master Data (Customer, Supplier, Item Master). UI berbahasa Indonesia. Versi/nomor rilis: **Not detected** (tidak ada file `VERSION`/tag rilis di repo).

- **Tidak ada `RowVersion`/optimistic concurrency** di satu pun entity, termasuk `NumberingConfig` yang rawan race condition saat generate nomor dokumen. **[DIKONFIRMASI 2026-09-07]** Gap ini sekarang terkonfirmasi jadi bug nyata: `RoleController.UpdatePermissions` melempar `DbUpdateConcurrencyException` saat 2 request edit permission role yang sama tumpang tindih (ditemukan di environment terpisah). Pola kode saat ini BUKAN delete-then-recreate seluruh baris — ini diff/merge (`RoleController.cs:89-137`): update in-place baris `Permission` yang modul-nya ada di payload, tambah baris baru untuk modul yang belum ada, dan hanya hapus baris yang modul-nya absen dari payload yang dikirim. Fix yang direkomendasikan (ganti pola individual jadi `ExecuteDeleteAsync` bulk + insert ulang) sudah didesain tapi **sengaja belum diimplementasikan** atas keputusan product owner (dampak rendah, cukup refresh manual).
